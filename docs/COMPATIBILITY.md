# Compatibility policy

A game is **Unknown** until tested. A successful import is not evidence that it runs.

Every positive record should include game version, macOS version, Mac architecture, runtime and version, graphics backend, settings, test date, and observed outcome. Keep Intel and Apple Silicon results distinct.

Steam sign-in must happen through the official Steam client. MacPlay must not request or store Steam passwords, cookies, or session tokens. DRM, third-party launchers, kernel drivers and anti-cheat can prevent execution; do not bypass those controls.
